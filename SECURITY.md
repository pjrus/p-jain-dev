# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Send a
private report to [paarangatj@gmail.com](mailto:paarangatj@gmail.com) with:

- a description of the issue and its impact;
- steps to reproduce the issue; and
- any suggested mitigation or patch.

Please allow reasonable time for investigation and remediation before sharing
the issue publicly. This project is a static portfolio and does not collect
account credentials or process form submissions on a server.
